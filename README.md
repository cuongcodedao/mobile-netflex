# 🎬 Netflex - Movie Streaming App

## 📌 Introduction

**Netflex** is an online movie streaming application

- **Backend**: Spring Boot + PostgreSQL
- **Mobile App**: Flutter
- **3rd Party API**: Integrated with [forum.ophim.cc](https://forum.ophim.cc/d/27-api-postman-ophim-otruyen) to fetch the latest movie data.

Features:  
✅ User authentication (Login / Register)  
✅ Profile management (add, delete, select profile)  
✅ Home page with movie categories  
✅ Movie detail page  
✅ Video streaming player  
✅ Favorite list  
✅ Watch history  
✅ Subscription plan selection
